# 第 2 周｜NumPy 与手写神经网络

**目标**：理解数组形状、线性回归、损失、梯度下降与两层 MLP。预计 5–7 小时。先完成第 1 周。

## 概念地图

训练就是循环执行：输入数据 → 模型预测 → 用损失衡量错误 → 求梯度 → 沿降低损失的方向更新参数。NumPy 只负责数组计算，本周的梯度由代码手写；这有助于理解第 3 周的自动求导。

## 动手

1. 运行 `python -m week02_numpy_nn.linear_regression`。在代码中找出 `X`、权重、预测、loss 和更新步骤，记录它们的形状。
2. 运行 `python -m week02_numpy_nn.mlp_classifier`。观察训练日志与 `outputs/` 下的曲线，确认 loss 总体下降。
3. 在 `week02_numpy_nn/mlp_classifier.py` 中标出 ReLU、softmax、交叉熵、反向传播对应的函数。
4. 运行 `python -m pytest tests/test_numpy_mlp.py -v`，阅读测试如何用数值梯度检查手写梯度。

## 练习与验收

- 将学习率改大、改小各运行一次，记录 loss 曲线和是否发散。改完恢复默认值。
- 解释为什么 softmax 的输入需要做数值稳定处理，为什么分类标签是整数索引。
- 验收：能画出“前向传播、loss、反向传播、更新”的流程；能解释权重矩阵的两维分别代表什么；测试通过。

**常见卡点**：矩阵乘法维度不匹配时，从最左侧输入形状逐层写出形状；loss 为 `nan` 时检查学习率和指数溢出。
