# 开始前：五分钟看懂这门课在做什么

**人工智能（AI）**是让程序完成通常需要人类判断的任务。**机器学习（ML）**让程序从样本中调整参数，而不是为每一种情况写死规则。**深度学习**使用多层神经网络；本教程从最小的数学例子出发，再训练衣物图片分类器。

## 一张图片如何变成预测

`图片 → 数字数组（Tensor）→ 模型 → 10 个分数（logits）→ 概率 → 类别`。这里的类别是 T-shirt/top、Trouser 等 10 种衣物。训练时还有已知答案（标签），程序比较预测与标签得到**损失（loss）**，再调整模型参数。预测新图片时不调整参数，这一步叫**推理**。

## 六个常用词

| 词 | 在本项目里的意思 |
|---|---|
| 样本 | 一张图片和它的真实类别 |
| 特征 | 图片中可供模型使用的数值与模式 |
| 参数 | 模型训练时会更新的权重和偏置 |
| epoch | 把训练集完整遍历一次 |
| batch | 一次送进模型的一小组样本 |
| checkpoint | 保存的模型参数及相关训练信息 |

## 三份数据的分工

- **训练集**用于更新参数。
- **验证集**用于比较不同设置并选择 checkpoint。
- **测试集**留到选择完成后，估计模型对未见数据的表现。

混用测试集和验证集会让最终分数过于乐观。你现在不必记住公式；学习第 2、3 周时再回来看这些词。

## 读代码时先问四个问题

输入是什么、形状是什么、输出是什么、这一行是否改变模型参数？例如图片 batch 的形状 `(B, 1, 28, 28)` 中，`B` 是一次处理的图片数，`1` 是灰度通道，后两个数是高和宽。第 4 周彩色 CIFAR-10 图片改为 3 个通道。
